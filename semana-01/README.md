# Semana 1: Central de Solicitações
## (central.py):
### Descrição:
    O projeto é sobre fazer um cadastro de uma solicitação, a pessoa faz sua solicitação dizendo seu nome, seu setor, o nível da categoria, o assunto e a descrição. O programa retorna o resultado com a solicitação estruturada.

### Tecnologias Utilizadas:
- Somente Python
- VSCODE

### Como Testar:
Siga os passos abaixo para acessar e rodar o script no seu ambiente:

1. **Abra o VS Code** no seu computador
2. **Abra a pasta do projeto**: Acesse `Arquivo` > `Abrir Pasta` (ou `File` > `Open Folder`) e selecione a pasta onde o projeto foi clonado
3. **Localize o arquivo**: No menu lateral esquerdo (Explorador), clique sobre o arquivo `central.py`
4. **Instale a extensão (se necessário)**: Certifique-se de que a extensão oficial do **Python** da Microsoft está instalada no VS Code
5. **Execute o arquivo**:
   * Abra o terminal integrado usando o atalho `Ctrl + '` (ou `Cmd + '` no Mac)
   * Digite o comando abaixo e aperte Enter:
     ```bash
     python nome_do_arquivo.py
     ```
   * *Alternativa:* Clique no botão **Play** (triângulo) no canto superior direito do editor
